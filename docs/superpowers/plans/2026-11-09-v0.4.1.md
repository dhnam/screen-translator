# v0.4.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 번역 앱 대상 판단을 `Target`(Exact/Missing)으로 정리하고, 시스템 바 잘라내기 옵션을 넣고, TODO의 사소한 항목을 정리해 v0.4.1로 릴리스한다.

**Architecture:** 판단과 계산은 순수 함수에 두고 테스트한다. 대상 판단은 `TargetResolver.resolve`, 잘라낼 영역 계산은 `CropRect.of`다. `AssistSession`과 `SettingsActivity`는 그 결과를 쓴다.

**Tech Stack:** Kotlin, JUnit 4, Robolectric 4.13 (기존과 같음)

**Spec:** `docs/superpowers/specs/2026-11-09-screen-translator-design.md` 14절(설계 검토 반영본)

## Global Constraints

- 잘라내기: 저장 키 `crop_system_bars`, 기본값 꺼짐
- 잘라내기 크기는 `WindowManager.currentWindowMetrics`의 `bounds`와 `getInsetsIgnoringVisibility(systemBars())`에서 얻는다. 세션 창 인셋은 쓰지 않는다.
- 새 문구 `crop_option`: "Remove status and navigation bars from the capture" / "캡처에서 상태바와 내비게이션 바 빼기" (영어·한국어 함께)
- 스크린샷 대기 시간 3000ms
- 이름·아이콘 조회 플래그는 `MATCH_DISABLED_COMPONENTS or MATCH_DISABLED_UNTIL_USED_COMPONENTS`
- `StubRecognitionService`는 바꾸지 않는다.
- 태그는 Task 5에서 `v0.4.1`

## Review Focus

1. **번역 앱 화면 이름이 바뀜**: 같은 패키지에 받는 화면이 하나면 그 화면으로 보내야 한다. 테스트: Task 1 `resolve_renamedActivity_singleMatch_isExact`.
2. **한 패키지에 받는 화면이 둘(구글)**: 시스템 선택 창을 띄우지 말고 공유 메뉴로 가야 한다. 테스트: Task 1 `resolve_renamed_twoMatches_isMissing`.
3. **비트맵 크기가 화면과 다름, 또는 비율이 다름**: 비율로 환산하거나 자르지 않아야 한다. 테스트: Task 2 `cropRect_scaledBitmap`, `cropRect_aspectMismatch_isNull`.
4. **잘못된 인셋**: 앱이 죽지 않고 원본을 보내야 한다. 테스트: Task 2 `cropRect_badInsets_isNull`.
5. **추가 선택 창을 연 직후 화면이 닫힘**: 사라진 화면에 창을 띄우려다 죽으면 안 된다. 테스트: Task 4 코드에서 `isFinishing || isDestroyed` 확인 + 기기 확인.

### Task 1: Target 판단, 이름·아이콘, 자기 제외, decode

**Files:** Modify `TargetResolver.kt`, `AssistSession.kt`(launch), `SettingsActivity.kt`(renderTargets), `TargetList.kt`. Test `TargetResolverTest.kt`, `TargetListTest.kt`

**Interfaces:**
- Produces:
  - `sealed interface Target { data class Exact(val component: ComponentName) : Target; object Missing : Target }`
  - `TargetResolver.resolve(c: ComponentName): Target`(명세 14절 A 규칙)
  - `TargetResolver.buildIntent(target: Target, uri: Uri): Intent`. 기존 `buildIntent(c?, uri)`와 `isAvailable`은 제거한다.
  - `label(c)`, `icon(c)`: 명세의 조회 순서와 플래그 그대로
  - 자기 제외: `base = selfPackage.removeSuffix(".dev")`, 제외 대상 `{base, "$base.dev"}`
  - `TargetList.decode`: `'/'`가 없는 항목을 버린다.
  - `AssistSession.launch`: 기본 앱이 없으면 `Missing`이다. 토스트는 `Exact`일 때 그 컴포넌트의 `label`로 띄운다.
  - `SettingsActivity.renderTargets`: `resolve(c) is Target.Missing`이면 회색으로 표시한다.

### Task 3: 세션에서 잘라내기·대기 시간·hide 정리

  - 설정 화면의 "여는 중…" 체크박스 아래에 `crop_option` 체크박스를 둔다.
