# v0.4.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 번역 앱 대상 판단을 세 단계로 정리하고, 시스템 바 잘라내기 옵션을 넣고, TODO의 사소한 항목을 정리해 v0.4.1로 릴리스한다.

**Architecture:** 판단과 계산은 순수 함수(`TargetResolver.status`의 결과 → `buildIntent`, `CropRect.of`)에 두고 테스트한다. `AssistSession`과 `SettingsActivity`는 그 결과를 쓴다.

**Tech Stack:** Kotlin, JUnit 4, Robolectric 4.13 (기존과 같음)

**Spec:** `docs/superpowers/specs/2026-11-09-screen-translator-design.md` 14절

## Global Constraints

- 잘라내기 저장 키 `crop_system_bars`, 기본값은 꺼짐
- 새 문구 `crop_option`: "Remove status and navigation bars from the capture" / "캡처에서 상태바와 내비게이션 바 빼기" (영어·한국어 함께)
- 스크린샷 대기 시간 3000ms
- 공유 타입 `image/png`(기존과 같음)
- 태그는 Task 5에서 `v0.4.1`

## Review Focus

1. **번역 앱 화면 이름이 바뀜(`PACKAGE_ONLY`)**: 설정 화면은 정상으로 표시하고, 홈버튼은 그 앱으로 보내야 한다. 테스트: Task 1 `status_packageOnly`, `buildIntent_packageOnly_setsPackage`.
2. **잘못된 인셋(음수, 화면보다 큼)**: 앱이 죽지 않고 원본을 보내야 한다. 테스트: Task 2 `cropRect_badInsets_isNull`.
3. **가로 화면**: 내비게이션 바가 옆에 있어도 그쪽을 잘라야 한다. 테스트: Task 2 `cropRect_landscapeSideBar`.
4. **음성 인식 껍데기에 권한을 붙인 뒤 어시스턴트 자격**: 목록에서 사라지면 안 된다. 테스트: Task 5 기기 확인(실패하면 되돌림).
5. **추가 선택 창을 연 직후 화면이 닫힘**: 백그라운드 결과가 사라진 화면에 창을 띄우려다 죽으면 안 된다. 테스트: Task 4 코드에서 `isFinishing`/`isDestroyed` 확인 + 기기 확인.

### Task 1: 대상 판단(TargetStatus)과 이름·자기 제외

**Files:** Modify `TargetResolver.kt`, `AssistSession.kt`(launch), `SettingsActivity.kt`(renderTargets의 `isAvailable` → `status`), `TargetList.kt`(decode). Test `TargetResolverTest.kt`, `TargetListTest.kt`

**Interfaces:**
- Produces:
  - `enum class TargetStatus { AVAILABLE, PACKAGE_ONLY, MISSING }`
  - `TargetResolver.status(c: ComponentName): TargetStatus`
  - `TargetResolver.buildIntent(c: ComponentName?, status: TargetStatus, uri: Uri): Intent`
    - `AVAILABLE` → `component = c`
    - `PACKAGE_ONLY` → `setPackage(c.packageName)`
    - `MISSING` 또는 `c == null` → 대상 없음(`finalIntent`에서 공유 메뉴)
  - `isAvailable`은 제거한다(호출처는 `status`로 바꾼다).
  - 자기 제외: `base = selfPackage.removeSuffix(".dev")`, 제외 대상은 `{base, "$base.dev"}`
  - `label`/`icon`: `PackageManager.MATCH_DISABLED_COMPONENTS` 사용. 활동 조회에 실패하면 앱 정보로 대체한다.
  - `TargetList.decode`: `'/'`가 없는 항목을 버린다.

- [ ] **Step 1: 실패하는 테스트**
  - `status_available`, `status_packageOnly`(같은 패키지의 다른 화면만 설치), `status_missing`
  - `buildIntent_available_setsComponent`, `buildIntent_packageOnly_setsPackage`, `buildIntent_missing_noTarget`
  - `shareTargets_excludesExactSelfAndDev_keepsLookalike`(`dev.dhnam.screentranslatorfoo`는 남음)
  - `label_disabledActivity_stillShowsAppName`
  - `decode_dropsEntriesWithoutSlash`
  - 기존 `isAvailable_*` 테스트는 `status_*`로 바꾼다.
- [ ] **Step 2: 실패 확인** — `./gradlew :app:testDebugUnitTest --tests '*TargetResolverTest*' --tests '*TargetListTest*'` / Expected: 컴파일 또는 단언 실패
- [ ] **Step 3: 구현 → 통과 확인**
- [ ] **Step 4: 호출처 바꾸기 → `./gradlew testDebugUnitTest assembleDebug`** / Expected: `BUILD SUCCESSFUL`
- [ ] **Step 5: Commit** — `feat: fall back to the app when the saved translator activity is gone`

### Task 2: 잘라내기 계산(CropRect)과 설정 값

**Files:** Create `CropRect.kt`, Modify `Prefs.kt`. Test `CropRectTest.kt`, `PrefsTest.kt`

**Interfaces:**
- Produces:
  - `data class CropRect(val x: Int, val y: Int, val width: Int, val height: Int)`
  - `companion fun of(width: Int, height: Int, left: Int, top: Int, right: Int, bottom: Int): CropRect?`
    - 인셋이 모두 0이면 null
    - 음수 인셋은 0으로 본다.
    - 결과 너비 < width/2 또는 높이 < height/2면 null
  - `Prefs.cropSystemBars: Boolean`(기본값 false)

- [ ] **Step 1: 실패하는 테스트**
  - `cropRect_noInsets_isNull`
  - `cropRect_portrait_topAndBottom`: (1080, 2400, 0, 80, 0, 120) → (0, 80, 1080, 2200)
  - `cropRect_landscapeSideBar`: (2400, 1080, 0, 80, 120, 0) → (0, 80, 2280, 1000)
  - `cropRect_badInsets_isNull`: (1080, 2400, 0, 2000, 0, 2000)
  - `cropRect_negativeInsets_treatedAsZero`
  - `cropSystemBars_defaultOff_andRoundTrip`
- [ ] **Step 2–3: 실패 확인 → 구현 → 통과 확인**
- [ ] **Step 4: Commit** — `feat: crop rectangle for system bars`
